# Examples

Progressive examples from basic projection to async and data interop:

1. `basic_structs` — fields, methods, and typing synthesis.
2. `tensor` — numeric class methods and projection.
3. `traits_protocols` — trait semantics and protocol-style output.
4. `errors` — `Result<T, E>` to exception modeling.
5. `async_inference` — async method metadata.
6. `numpy_zero_copy` — contiguous buffers for zero-copy strategy.
7. `polars_bridge` — columnar analytics-oriented shapes.
8. `jupyter_demo` — notebook-facing API surfaces.
9. `arrow_bridge` — Arrow-compatible schema groundwork.
10. `notebook_experience` — rich notebook ergonomics.
11. `llm_runtime` — async LLM runtime projection.
12. `high_performance_tensor` — high-throughput tensor kernels.
13. `ferryx_tensor_runtime` — self-hosting stress validation runtime.

Each example contains:

- compilable Rust source,
- focused README,
- expected generated `.pyi` artifact sketch.
