# Support

## Getting Help

- **Usage questions**: GitHub Discussions.
- **Bug reports**: GitHub Issues with reproduction and environment details.
- **Security concerns**: `security@ferryx.dev` (private).
- **Design questions**: RFC discussion threads.

## What to Include

For useful support turnaround, include:

- ferryx version(s).
- Rust toolchain and Python version.
- OS/architecture.
- Minimal reproducible source.
- Expected vs actual output.
- Relevant logs/tracebacks.

## Response Expectations

- Critical security: best effort within 72 hours.
- Reproducible bugs: triage target within 7 days.
- Feature requests: evaluated during roadmap triage cycles.

## Support Boundaries

We maintain ferryx itself and official examples.
We cannot provide deep support for private downstream application architecture.
