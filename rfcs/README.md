# RFCs

RFCs are required for changes that alter long-term compatibility or architecture.

## RFC Required Topics

- ABI changes
- IR schema changes
- macro syntax changes
- async model changes
- ownership semantics changes
- new language targets

## Process

1. Copy `rfcs/RFC_TEMPLATE.md`.
2. Open PR with filename: `rfcs/NNNN-short-title.md`.
3. Discuss alternatives and migration impact.
4. Achieve maintainer approval.
5. Implement behind tracking issue(s).

Inspired by Rust RFCs, Swift Evolution, and Python PEP process discipline.
