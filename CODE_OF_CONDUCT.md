# Ferryx Code of Conduct

ferryx is an infrastructure project. We care about precision, rigor, and respectful collaboration.

## Our Standard

In all project spaces (issues, pull requests, discussions, chat, events), contributors are expected to:

- Assume good intent, then ask for technical clarity.
- Critique code and decisions, not people.
- Prefer evidence over authority: benchmarks, traces, docs, and reproducible cases.
- Leave the codebase better documented than they found it.
- Respect maintainer time by providing minimal reproductions and complete context.

## Unacceptable Behavior

- Harassment, intimidation, hate speech, sexualized language, or personal attacks.
- Repeatedly dismissing reviewer feedback without technical argument.
- Deliberate misinformation about performance, safety, or compatibility claims.
- Publishing private security details before coordinated disclosure.
- Disruptive behavior that prevents engineering work.

## Engineering Conduct Expectations

For ferryx specifically:

- Unsafe Rust requires explicit safety comments and reviewer sign-off.
- ABI-affecting changes require an RFC and compatibility note.
- Performance-sensitive changes require benchmark evidence.
- Public API changes require migration notes or deprecation pathways.

## Scope

This policy applies to:

- GitHub repositories, issues, pull requests, discussions.
- Official project communication channels.
- Public and private spaces when someone is representing ferryx.

## Reporting

Report issues to: `security@ferryx.dev` (for security) or `conduct@ferryx.dev` (for conduct).

Provide:

- Links/screenshots/logs.
- Timestamp and participants.
- Any prior moderation context.

## Enforcement

Maintainers may apply one or more actions:

1. Informal warning.
2. Temporary interaction restriction.
3. Temporary or permanent ban from project spaces.
4. Revert or lock disruptive threads.

Enforcement decisions prioritize contributor safety and project continuity.

## Attribution

Inspired by established OSS conduct standards, adapted for ferryx's infrastructure-first engineering culture.
