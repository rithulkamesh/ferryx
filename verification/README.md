# Verification Platform

This directory contains executable end-to-end validation workflows.

## Layout

- `smoke/`: minimal build/install/import checks.
- `golden/`: generated output golden assertions.
- `notebooks/`: notebook-oriented verification.
- `stress/`: repeated generation and parse stress tests.
- `compatibility/`: cross-version compatibility checks.
- `wheel/`: wheel metadata and import validation.
- `snapshot/`: semantic snapshot baselines and reports.
- `prompts/`: AI-assisted semantic verification prompts.
- `personas/`: realistic user persona test projects.
- `cross_target/`: semantic parity validation across emitters.
